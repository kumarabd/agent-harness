agent-harness-shared has been deployed.

This is the SHARED, tenant-agnostic loop-worker pool
(docs/components/multi-tenancy.md) — deployed ONCE for the whole cluster,
unlike agent-harness-tenant which is one release per tenant. It deploys:

  - {{ include "agent-harness-shared.fullname" . }}
    (Go — Session Coordinator + Turn Workflow; serves every namespace listed
    in temporal.namespaces from every replica)

It does NOT deploy Temporal server itself, and does NOT deploy any
tenant-specific components (tenant workers, Postgres, tenant PV — those
come from the agent-harness-tenant chart, one release per tenant).

This release is currently configured to serve:

  Temporal address:     {{ .Values.temporal.address }}
  Temporal namespaces:  {{ join ", " .Values.temporal.namespaces }}
  Task queue:           {{ .Values.temporal.taskQueue }}

Check the pool is actually connecting:

  kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }}

You should see one line per namespace above:
  "loop worker starting: temporal=... namespace=... task_queue=..."

A namespace that fails to start (unreachable, or doesn't exist yet in
Temporal — see `temporal operator namespace create <name>`) logs a retry
line with growing backoff instead of crashing the pod; it does NOT affect
the other namespaces this same release is already serving. If you just added
a namespace and don't see its "starting" line, check for:

  kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} | grep "stopped with error"

Onboarding a new tenant: add its Temporal namespace to temporal.namespaces
and `helm upgrade` this release. This rolls every replica of this shared
pool — safe (Temporal workflow executions survive worker restarts via
history replay), but it does mean every tenant onboarding touches this one
release, a deliberate trade — see multi-tenancy.md.

Note: the ModelCall/ToolCall/Persist/Deliver/CompressContext activities that
this pool's workflows dispatch to are implemented by each tenant's own
agent-harness-tenant release (tenant-worker), not by anything in this
chart.
